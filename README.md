# Sway GIF Tool (Rust)

読み込んだ画像を Rust のパワーで滑らかに揺らし（Sway）、2秒間のループアニメーションとして高品質な **GIF** 形式でエクスポートできるシンプルなデスクトップツールです。

UI に `egui`、描画に `macroquad` を採用し、直感的な操作と高速な動作を実現しています。

## 🚀 特徴

- **カンタン画像読み込み**: `rfd`（ネイティブファイルダイアログ）による直感的なファイル選択。
- **リアルタイム調整**: 揺れの「強さ」と「速さ」をスライダーで自由に変更可能。
- **自動フィット**: どんなサイズの画像でも、アスペクト比（縦横比）を維持したまま画面にぴったり自動調整。
- **ワンクリック録画**: 2秒間のアニメーションを自動でキャプチャし、タイムスタンプ付きの GIF として即座に保存。
- **完全日本語化**: 豆腐文字（四角文字）を解消し、見やすい日本語 UI を搭載。

---

## 🛠️ 前提条件 (動作環境)

本ツールは **Windows** 環境をベースにフォントを設定しています。
ビルドには Rust の開発環境（MSRV 1.2021 以降推奨）が必要です。

- **C++ ビルドツール**: Visual Studio 2022 (Community 等) の「C++ によるデスクトップ開発」ワークロードが必要です。

## 📦 使い方

### 1. リポジトリのクローン / 準備
プロジェクトのディレクトリに移動します。

```bash
cd rust-animation-app
2. アプリケーションの起動
初回起動時はビルドが行われるため、少し時間がかかります。

Bash
cargo run
3. 操作手順
画面左側のパネルにある 「📁 画像を読み込む」 ボタンをクリックし、PNG または JPG 画像を選択します。

「強さ」 と 「速さ」 のスライダーを動かして、お好みの揺れ具合に調整します。

「🎬 GIF保存 (2秒)」 ボタンを押すと録画が始まり、2秒後にプロジェクトのルートディレクトリに sway_年月日-時分秒.gif という名前で保存されます。

⚠️ トラブルシューティング
画面の文字が「□□□」と表示される場合
本ツールは Windows 標準の C:\Windows\Fonts\msgothic.ttc を読み込む仕様になっています。
もし他OS（Mac/Linux）で動かす場合は、src/main.rs 内のフォントパスを、環境に合わせた日本語フォント（TTF/TTC）に書き換えてください。
